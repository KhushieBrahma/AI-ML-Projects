# CartPole Reinforcement Learning

## 📌 Project Overview

This project demonstrates the basics of Reinforcement Learning using the CartPole-v1 environment from Gymnasium.

An agent interacts with the environment by selecting actions, receiving rewards, and attempting to balance a pole on a moving cart.

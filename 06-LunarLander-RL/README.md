# 🚀 LunarLander Reinforcement Learning using Deep Q-Network (DQN)

## 📌 Project Overview

This project demonstrates Reinforcement Learning using the Deep Q-Network (DQN) algorithm to solve the LunarLander-v2 environment from Gymnasium.

The objective is to train an intelligent agent that learns how to safely land a spacecraft by interacting with the environment and maximizing cumulative rewards.

---

## 🧠 Algorithm Used

- Deep Q-Network (DQN)

---

## 🛠️ Technologies Used

- Python
- Gymnasium
- Stable-Baselines3
- PyTorch
- NumPy
- Matplotlib
- Box2D
- Pygame

---

## 📂 Dataset

This project does not use a traditional dataset.

The agent learns by interacting with the **Gymnasium LunarLander-v2** simulation environment.

---

## 📋 Workflow

1. Import required libraries
2. Create the LunarLander environment
3. Initialize the DQN model
4. Train the agent
5. Evaluate model performance
6. Test the trained agent
7. Save the trained model
8. Load the saved model
9. Analyze results

# Face Recognition using Labeled Faces in the Wild (LFW)

## 📌 Project Overview

This project implements a face recognition system using the Labeled Faces in the Wild (LFW) dataset.

Principal Component Analysis (PCA) is used for feature extraction, while a Support Vector Machine (SVM) classifier performs face recognition.

---

## Dataset

- Labeled Faces in the Wild (LFW)
- Grayscale face images
- Multiple individuals
- Images collected from the web

---

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

---

## Machine Learning Pipeline

- Dataset Loading
- Data Visualization
- PCA (Eigenfaces)
- SVM Classification
- Accuracy Evaluation
- Classification Report
- Confusion Matrix
- Prediction
- Model Saving
